# RespawnLab – Sitio Web Corporativo
¡Bienvenido al repositorio del sitio web de **RespawnLab**! Este proyecto experimental consiste en una landing page responsive que presenta los servicios de RespawnLab, una empresa dedicada a soluciones informáticas integrales: desarrollo de aplicaciones, ERP a medida, servicio técnico y ciberseguridad.

## Características
- **Navbar responsiva** con logotipo y enlaces ancla.
- **Carrusel** con tres banners promocionales y captions semitransparentes.
- **Sección de servicios** con _cards_ ilustradas (Desarrollo, ERP, Servicio Técnico, Ciberseguridad).
- **Formulario de contacto** accesible y validado por el navegador.
- **Diseño mobile‑first** gracias a Bootstrap 5.
- **Estilos personalizados** en `styles.css` (fuente *Poppins*, colores corporativos azul & blanco).

---

## Tecnologías
| Herramienta | Uso |
|-------------|-----|
| **HTML 5** | Maquetación semántica |
| **CSS 3 / SCSS** | Estilos personalizados |
| **Bootstrap 5.3** | Sistema de rejilla, componentes UI |
| **JavaScript** | Interactividad básica (Bootstrap Bundle) |
| **[Google Fonts – Poppins](https://fonts.google.com/specimen/Poppins)** | Tipografía |

> **Nota:** Bootstrap y Poppins se cargan vía CDN para evitar instalaciones adicionales.
